# ── wizkoo.com publish allowlist ────────────────────────────────────────────
#
# THIS FILE DECIDES WHAT WIZKOO.COM SERVES.
#
# `npm run build` copies exactly the paths named under `publish:` into _site/,
# and Netlify serves _site/. A file that is not named here is not on the
# website. The repository is no longer the website.
#
# TO SHIP A NEW PAGE: add one line under `publish:`. That is the whole edit.
#
# `declined:` IS AN ACKNOWLEDGEMENT REGISTER, NOT AN EXCLUSION MECHANISM.
# A root-level .html file is already excluded by not appearing under
# `publish:`; listing it under `declined:` only records that a human looked at
# it and said "not a page", which stops the guard failing the build over it.
# Deleting an entry from `declined:` does not publish anything. It fails the
# build.
#
# THE GUARD (scripts/build-site.js). Every root-level .html file in the repo
# must appear in exactly one of the two sections:
#     in neither  -> build FAILS. A new page nobody accounted for.
#     in both     -> build FAILS. The manifest contradicts itself.
# Absence is never permission.
#
# SYNTAX
#     A line starting with # is a comment. Blank lines are ignored.
#     Section headers are `publish:` and `declined:` at column 0.
#     Entries are indented, one path per line, repo-relative, forward slashes.
#     A trailing `# ...` on an entry is its reason. Required under `declined:`.
#     Globs: * matches within one path segment, ** matches across segments.
# ────────────────────────────────────────────────────────────────────────────
